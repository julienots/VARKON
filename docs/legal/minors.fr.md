# Protection des mineurs

- Aucun achat avec de l'argent réel dans cette version.
- Les prix en monnaie du jeu sont toujours affichés avant l'achat, avec une confirmation (désactivable dans les paramètres).
- Pas de compte à rebours trompeur, pas de fausse réduction : les offres quotidiennes changent réellement à minuit (heure de l'appareil).
- Les probabilités des coffres sont affichées et calculées à partir des tables réellement utilisées.
- La campagne complète se termine sans aucune dépense réelle.
- Avant toute publication avec achats, les obligations des marchés visés (classification PEGI/IARC, règles locales sur les coffres) devront être vérifiées par SuperEssence Studio.
