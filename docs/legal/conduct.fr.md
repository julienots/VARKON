# Code de conduite

Cette version ne comporte aucune fonction sociale. Si des fonctions en ligne sont ajoutées, sont interdits :
- le harcèlement et les menaces ;
- la fraude et l'usurpation d'identité ;
- le piratage et la modification du client ou des sauvegardes ;
- l'exploitation volontaire de bugs ;
- la triche compétitive.

Des outils de signalement et de modération seront fournis avec toute fonction sociale.
