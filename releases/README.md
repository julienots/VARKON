# VARKON 0.10.0 — APK de test

- `VARKON-0.10.0-debug.apk` : Android 5.0+ (API 21), arm64-v8a et armeabi-v7a.
- Signé avec une clé de **débogage** : installation directe uniquement (activer « Installer des
  applications inconnues »), ne convient pas au Google Play Store.
- Installation : copier l'APK sur le téléphone et l'ouvrir, ou `adb install -r VARKON-0.10.0-debug.apk`.
- Empreinte : voir `SHA256SUMS.txt`.

Détails, limites et problèmes connus : `docs/STATUS.md`.
